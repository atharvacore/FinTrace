# Sample data

## `synthetic_transactions.csv`: SYNTHETIC, not PaySim

5,000 rows produced by `scripts/generate_sample_data.py --rows 5000 --seed 42`
(regenerating it with the same arguments produces an identical file, which a test checks).

- Same columns as PaySim, so the importer, the API and the demo work before you download PaySim.
- 108 rows (≈2%) are labelled `isFraud=1`. That is ~16× PaySim's real fraud rate, chosen so a small
  demo has something to investigate.
- It is generated by a short rule-based script. **Model metrics computed on this file say nothing
  about real-world performance and must never be reported as results.**
